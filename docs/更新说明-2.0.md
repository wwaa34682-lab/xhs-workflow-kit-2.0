# 2.0 更新说明

## 相对此前版本新增了什么

增加一条 **活动向可选路径**（详见 `docs/活动向搜首图与AI分系列出图.md`）：

1. **搜对标首图**：用 TikHub 小红书笔记搜索（`search_notes`）按主题 / 时间窗 / 官方·相关行业·不限等口径批量采封面；密钥只走环境变量 `TIKHUB_API_KEY`；交付编号合集 + `posts.csv`；严格口径凑不满也不用排除类型凑数。
2. **AI 分系列出图**：用户选定的每一张种子封面单独开一个 AI 出图对话框（一封面 = 一系列 = 一个对话）；同系列气质统一、布局可不同；首图只放活动简介，细则放内页；logo 只用品牌原文件合成并做质检。
3. **同对话框文案**：标题与正文在该系列出图对话里写完，再对照已确认活动事实核数字；缺口标【待业务确认】。

## 什么没有变

- **10 步闭环**（对标 → 文案 → 出图 → 评审 → 发布 → 数据 → 投流 → 复盘）结构不变。
- 默认出图仍是 `steps/05` 的**参考图二选一 + `render_post.py`**；本路径是用户明确选择活动战役时的**额外选项**，不替换、不削弱主路径。
- 铁律不变：不编造事实、不代发不代投、人工关卡、对标只做研究、含 AI 须声明等（见 `AGENTS.md`）。
