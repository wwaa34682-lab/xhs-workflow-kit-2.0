# 可选路径（2.0）：活动向搜首图 → AI 分系列出图 → 同对话框文案

本文件描述 kit **2.0 可选路径**。

本路径是 **第 01 / 05 步的活动向补充**，不替换默认的 `render_post.py` 参考图改编流程。适用于双十一、开门红、会员日等**活动海报型**图文：先批量搜对标首图给用户挑选，再按「一封面 = 一系列 = 一个 AI 出图对话框」出整套图，并在同一对话框里写标题和正文。

用户未明确选择本路径时，仍按 `steps/05-选模板与出图.md` 的两个选项走。

---

## D. 在 10 步闭环里的位置

| 环节 | 落点 |
|---|---|
| 搜对标首图 | 补充第 01 步（活动向对标收集），或作为第 05 步前置 |
| 分系列出图 + 同对话框文案 | 第 04 / 05 步的可选替代：用户选定本路径后，可不走 `render_post.py`，改用 AI 对话出图与文案 |
| 交付之后 | 照常进入第 06–10 步（专家评审 → 发布队列 → 数据回收 → 投流 → 复盘） |

铁律不变：不编造事实；不代发、不代投；缺业务事实写【待业务确认】；含 AI 画面时提醒用户勾选「含AI生成内容」。

## A. 搜对标首图

### 开工前先问清（一次问清，带推荐默认）

1. **主题**：活动名或品类关键词（如「双十一」「会员日」「开门红」+ 行业词）。
2. **数量**：要几张首图合集（常见 20–30）。
3. **时间窗**：`一天内` / `一周内`（或接口支持的等价筛选项）。
4. **筛选口径**：`官方` / `相关行业` / `不限`。  
   - 选「官方」时，不要用专柜导购、买手号、UGC 凑数。  
   - 严格口径凑不满 N 张时：**有多少交多少**，并说明缺口，绝不拿已排除类型垫数。

用户确认后再调用接口；每轮交付后等用户挑「种子封面」，不要擅自开系列出图。

### 搜索方式（TikHub 小红书笔记搜索）

- 使用 TikHub 小红书 **`search_notes`**（或同名笔记搜索）接口。**按成功调用计费**，控制翻页次数。
- **鉴权**：只从环境变量 `TIKHUB_API_KEY` 读取；**禁止**打印、写入仓库、贴进聊天记录或截图。本 kit **不内置密钥**；各项目可自备薄封装（例如本地的 `tikhub_source.py`），密钥仍只走环境变量。
- 常用参数（名称以当前 API 文档为准）：
  - `keyword`：检索词
  - `page`：页码
  - `sort_type`：`popularity_descending`（最热）或 `time_descending`（最新）
  - `time_filter`：与用户选的时间窗对齐
  - `note_type`：需要时限定图文等类型
- 关键词组合建议：
  - 主题 + 品类/品牌词 + `双十一` / `双11` / `礼遇` 等活动词；
  - 要「官方」时再加 `官方` / `旗舰店`；
  - 「相关行业」用相邻品类词扩搜，仍按口径过滤作者类型。
- **去重**：按 `note_id`（或等价唯一 ID）去重。
- **下载**：只拉封面图；正文/互动等写入表。字段缺失标 **「待补」**，**禁止编造**点赞、日期、作者身份。
- **交付**：
  - 编号合集（contact sheet，每格对应编号）；
  - `posts.csv`（至少含编号、note_id、标题/链接、作者、时间、筛选备注）；
  - 口头或文档中报告**约略调用次数与费用**；
  - 等用户点名选用哪些封面作为系列种子。

对标图仅作研究与风格参考，不商用、不搬运原图进成品（见 `docs/注意事项.md`）。

## B. 分系列 AI 出图

1. **一封面 = 一系列 = 一个独立 AI 出图对话**（例如 ChatGPT 图像对话）。不同系列不要混在同一个对话框里。
2. **同系列**：角色、色板、视觉语言一致；版式布局可以不同。**不同系列**必须一眼能区分，不要只换角色、版式照搬成「同一套皮」。
3. **首图**：只放活动简介级信息；具体权益、价档、细则放在后面几张内页。
4. **Logo**：只用品牌配置里的**原版文件**合成；禁止重绘、改色、用 AI「画一个像的」。避免白底方块贴纸感；合成后**放大检查重影 / 双描边**（旧 AI logo 区域要清干净再贴）。Logo 变体（例如节日色点）以品牌本地配置为准，本公开文档不写死某一品牌规则。
5. **画面禁写**：未确认的门店名、地址等不要上图；不确定的文案不要硬编。
6. **交付前质检**：错别字/乱码、错误或变形 logo、布局压字、明显 AI 瑕疵；有问题先修再给用户。

本路径出的图进入 `data/drafts/<稿件ID>/`（或项目约定目录），并在稿件备注里标明「活动向 AI 分系列路径」，便于第 06 步评审对照。

---

## C. 文案

1. **标题与正文在同一出图对话框里生成**（与该系列图像上下文一致），再拷回稿件 `copy.md`（或等价文件）。
2. **数字与权益**必须对照用户已确认的活动源（海报、`brand.yaml` 活动字段等）核对；对不上或未知的写 **【待业务确认】**，集中问用户，禁止猜价格或规则。
3. 文案、标签交给用户过目；用户确认后再进第 06 / 07 步。
4. **发布与投流**：kit 铁律不变——agent **不自动发帖、不代跑广告**，除非用户明确指令并完成确认；适用时提醒勾选「含AI生成内容」。

---

## 与默认出图路径的关系

- 默认路径：`steps/05` 二选一 + `render_post.py`（参数化版式、风格锁强制校验）。  
- 本可选路径：活动战役、需要对标首图合集、且用户接受用 AI 对话出整套 KV 时使用。  
- 二者不要静默混用：同一稿件选定一种主路径；若中途切换，向用户说明并归档参考图 / 对话记录。
